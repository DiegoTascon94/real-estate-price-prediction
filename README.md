# 🏠 Real Estate Intelligence: Modelado Predictivo y Análisis de Atribución

## 🎯 Contexto del Negocio
En el sector inmobiliario digital, el éxito depende de la precisión en la valoración de activos y la eficiencia en la adquisición de usuarios. Este proyecto combina el **análisis predictivo de precios** con el estudio de **logs de comportamiento y costos**, permitiendo entender no solo cuánto vale una propiedad, sino qué canales de marketing son más rentables.

## 🚀 Objetivo del Proyecto
* **Estimar el valor de mercado** de propiedades mediante modelos de regresión.
* **Analizar el Journey del Usuario** mediante logs de visitas y órdenes.
* **Optimizar el ROI de Marketing** evaluando la relación entre el costo de adquisición (CAC) y las transacciones finales.

## 📂 Estructura del Repositorio
```text
├── predictive_housing_insights.ipynb  # Notebook con análisis y modelado
├── analytics_logs.csv                 # Logs de eventos y comportamiento
├── costs_us.csv                       # Datos de inversión en marketing
├── orders_log_us.csv                  # Registro de transacciones y órdenes
├── visits_log_us.csv                  # Historial de tráfico de usuarios
├── requirements.txt                   # Librerías necesarias
└── README.md                          # Documentación del proyecto
```

## 🛠️ Tecnologías y Herramientas
* **Stack:** Python (Pandas, NumPy, Scikit-learn).
* **Visualización:** Matplotlib, Seaborn.

## 📝 Conclusiones
El proyecto integra el Real Estate con el Marketing Analytics. La capacidad de predecir el precio de un activo y, al mismo tiempo, entender qué canal de marketing trajo al comprador, permite una gestión integral de la rentabilidad, optimizando tanto el inventario como la adquisición.
